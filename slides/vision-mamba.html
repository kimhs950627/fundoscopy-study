1. ViT 복습

왜 바꾸려는가

이미지를 패치 토큰 x₁…x_L 로 만들고, attention으로 모든 토큰 쌍을 비교한다. L이 커지면 연산·메모리가 L²로 폭증.

$$ \mathrm{Attention}(Q,K,V) = \mathrm{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d}}\right)V, \qquad \text{cost} = O(L^2 D) $$

L이 2배 → attention 4배, SSM 2배. 고해상도일수록 격차 폭증.

2. 출발점

상태공간모델(SSM)

$$ h'(t) = A\,h(t) + B\,x(t), \qquad y(t) = C\,h(t) + D\,x(t) $$
기호의미
h은닉 상태 = 정보의 압축 메모리
A상태 전이
B입력 주입
C출력 읽기
D지름길(skip)

직관

Attention = 모든 토큰을 저장 후 매번 전부 조회.
SSM = 하나의 요약 메모리를 순서대로 갱신하며 읽는다 → O(L).

4. 계산 방식

같은 식, 두 가지 계산

추론: 재귀(순차)

$$ h_t = \bar A h_{t-1} + \bar B x_t $$

앞에서 뒤로 하나씩 · O(L)

학습: 컨볼루션(병렬)

$$ y = x * K $$

고정 커널이면 병렬 · O(L)

전개:  K = ( C B̄ ,  C Ā B̄ ,  C Ā² B̄ ,  ... )   # 고정 커널(LTI)
고정 커널은 재사용 가능하지만 “입력에 따라 선택”은 불가 → 다음 절(선택성).

5. Mamba 핵심

선택성 (Selective SSM)

Δ,B,C를 입력 x_t마다 다르게 만든다 → “무엇을 기억/무시할지”를 입력이 결정.

$$ \Delta_t = \mathrm{softplus}(\mathrm{Linear}_{\Delta}(x_t)), \quad B_t = \mathrm{Linear}_B(x_t), \quad C_t = \mathrm{Linear}_C(x_t) $$ $$ h_t = \bar A_t h_{t-1} + \bar B_t x_t, \qquad y_t = C_t h_t + D x_t $$

LTI(상수)

커널 고정 → 합성곱 가능, 선택 불가

Selective(입력 의존)

커널이 매번 달라짐 → 합성곱 불가 → 병렬 스캔

Vision Mamba
5. 수식 ③

병렬 스캔 (associative scan)

$$ h_t = a_t h_{t-1} + b_t, \quad a_t = \bar A_t,\ b_t = \bar B_t x_t $$ $$ (a_2,b_2)\circ(a_1,b_1) = \big(a_2 a_1,\; a_2 b_1 + b_2\big) \quad\text{(결합법칙 성립)} $$

수치 예: a=[0.5,0.5,0.5], b=[1,0,2]

1(0.5000, 1.0000)1.0000

결합법칙 → O(L) 작업을 O(log L) 깊이로 병렬화 (Blelloch / CPU는 tf.scan).

6. 코드

PyTorch — 정답 오라클(순차 루프)

import torch, torch.nn.functional as F

def selective_scan(u, delta, A, B, C, D=None):
    # u, delta: (b, d, l)   A: (d, n)   B, C: (b, n, l)
    b, d, l = u.shape; n = A.shape[1]
    delta = F.softplus(delta)                 # Δ > 0
    dA   = torch.exp(delta[..., None] * A)    # exp(ΔA) -> (b,d,l,n)
    dB_u = (delta[..., None]
            * B.transpose(1, 2)[:, None]
            * u[..., None])
    h = u.new_zeros((b, d, n)); ys = []
    for t in range(l):
        h = dA[:, :, t] * h + dB_u[:, :, t]   # h_t = Ā h_{t-1} + B̄ x_t
        ys.append(torch.einsum("bdn,bn->bd", h, C[:, :, t]))
    y = torch.stack(ys, dim=2)
    return y + u * D.view(1, -1, 1) if D is not None else y
이 구현이 정답 기준. 다음 슬라이드의 병렬 버전과 수치 일치(허용오차 < 1e-5)를 확인.

6. 코드

TensorFlow — tf.scan 병렬화

import tensorflow as tf

def selective_scan_tf(u, delta, A, B, C):
    # u, delta: (b, l, d)   A: (d, n)   B, C: (b, l, n)
    delta = tf.nn.softplus(delta)
    dA  = tf.exp(delta[..., None] * A)                 # (b,l,d,n)
    dBu = delta[..., None] * B[:, :, None, :] * u[..., None]

    def step(h, xs):
        dA_t, dBu_t, C_t = xs
        h = dA_t * h + dBu_t
        y = tf.reduce_sum(h * C_t[:, None, :], axis=-1)
        return h, y

    h0 = tf.zeros([tf.shape(u)[0], tf.shape(u)[2], A.shape[1]])
    _, ys = tf.scan(step, (tf.transpose(dA, [1,0,2,3]),
                           tf.transpose(dBu,[1,0,2,3]),
                           tf.transpose(C,  [1,0,2])), initializer=h0)
    return tf.transpose(ys, [1,0,2])

7. 아키텍처

양방향 스캔 — 이미지는 순서가 없다

한 방향 스캔은 패치 순서에 민감 → 정방향 + 역방향을 합친다.

$$ y = \mathrm{SSM}_{\text{forward}}(x) + \mathrm{flip}\big(\mathrm{SSM}_{\text{backward}}(\mathrm{flip}(x))\big) $$
정방향 SSM →
← 역방향 SSM
ViT는 순열 불변(방향 없음), SSM은 방향 의존 → 양방향이 필수.
