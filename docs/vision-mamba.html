Vision Mamba, 쉽게 이해하기

ViT를 아는 사람을 위한 애니메이션 설명 · Attention(느린 전역) → SSM(빠른 전역)
ViT: O(L²) → Mamba: O(L)

한 줄 요약

Attention이 “모든 토큰을 매번 전부 조회”라면, Vision Mamba는 입력이 조절하는 요약 메모리(상태)를 양방향으로 순차 갱신해서 O(L)로 같은 전역 문맥을 얻습니다.

스크롤하면 각 개념이 애니메이션으로 나타납니다. 슬라이더와 버튼으로 직접 조작해 보세요.

ViT 복습 — 왜 바꾸려는가

ViT는 이미지를 패치로 쪼개 토큰 x₁…x_L 로 만들고, attention으로 모든 토큰 쌍을 비교합니다. L이 커지면 연산·메모리가 L²로 폭증합니다.

Attention(Q,K,V) = softmax(QKᵀ/√d) V     # 모든 쌍 비교
복잡도 = O(L² · D)

모든 쌍을 비교한다는 것 (아래 격자가 전부 켜지는가?)

8×8 = 64칸 = L². 토큰 8개를 전부 비교하면 64번. L=100이면 10,000번.

출발점 — 상태공간모델(SSM)

h'(t) = A · h(t) + B · x(t)     ← 상태(메모리) 갱신
y(t)  = C · h(t) + D · x(t)     ← 상태에서 출력 읽기
기호의미
h은닉 상태 = 지금까지 본 정보의 압축 메모리
A상태 전이 (과거를 다음으로 넘김)
B입력 주입 (새 토큰 반영)
C출력 읽기 (상태에서 꺼냄)
D지름길(skip)

토큰을 순서대로 “메모리에 적기”

상태 h = 0.00

토큰 하나씩 읽으며 상태를 갱신합니다. 전부 저장하지 않고 요약하므로 O(L).

이산화와 Δ — 얼마나 기억할까

Ā = exp(Δ · A)                 # 상태가 남는 정도
B̄ = Δ · B                      # 입력을 받는 정도
h_t = Ā · h_{t-1} + B̄ · x_t
y_t = C · h_t

Δ(스텝)를 조절하면 “과거 상태를 유지” ↔ “현재 입력을 반영” 이 서로 맞바뀝니다. 슬라이더를 움직여 보세요.

Δ = 1.00
과거 상태 유지 (Ā = e^(−Δ))
현재 입력 반영 (B̄ ∝ Δ)

Δ가 크면 → 현재 입력을 강하게 반영(과거는 잊음). Δ가 작으면 → 상태를 오래 유지.

재귀 vs 컨볼루션 — 같은 식, 두 가지 계산

SSM은 같은 수식을 두 방식으로 계산합니다. 토글을 눌러 비교하세요.

재귀: 앞에서 뒤로 하나씩 (O(L))
재귀:  h_t = Ā h_{t-1} + B̄ x_t
전개:  y = x * K ,  K = (C B̄, C Ā B̄, C Ā² B̄, ...)   # 고정 커널이면 병렬!

수식 ① — 이산화: Δ는 어디서 오나

연속 방정식에서 출발합니다.

$$ h'(t) = A\,h(t) + B\,x(t), \qquad y(t) = C\,h(t) + D\,x(t) $$

구간 전체에서 입력이 일정하다고 보는 영차홀드(ZOH) 해는 정확히

$$ \bar A = e^{\Delta A}, \qquad \bar B = \Big(\int_{0}^{\Delta} e^{\tau A}\,d\tau\Big) B = A^{-1}\big(e^{\Delta A} - I\big) B $$

A가 대각(스칼라)이면 적분도 스칼라라 간단합니다. Mamba는 행렬 역산을 피하려 1차 근사 B̄ ≈ ΔB 를 씁니다.

Δ정확한 B̄ = (1 − e^(−Δ))/1근사 B̄ = ΔB

Mamba가 A = −exp(A_log) 로 두는 이유: A가 항상 음수 → Ā = e^(ΔA) ∈ (0,1) → 재귀가 수축(contractive) → 기울기 폭주·소실 없이 안정.

수식 ② — 재귀에서 컨볼루션으로

재귀를 차례로 풀어 씁니다 (h₀ = 0).

$$ h_t = \bar A h_{t-1} + \bar B x_t $$ $$ h_1 = \bar B x_1,\qquad h_2 = \bar A\bar B x_1 + \bar B x_2,\qquad h_3 = \bar A^2\bar B x_1 + \bar A\bar B x_2 + \bar B x_3 $$

일반형과 출력을 정리하면

$$ h_t = \sum_{s=1}^{t} \bar A^{\,t-s}\,\bar B\,x_s, \qquad y_t = C h_t = \sum_{k=0}^{t-1}\underbrace{\big(C\bar A^{k}\bar B\big)}_{K_k}\,x_{t-k} = (K * x)_t $$

즉 고정 커널 K 와의 인과적 합성곱입니다. A=−1, B=C=1, Ā=0.6065, B̄=0.5, x=[1,0,2] 로 검산:

커널값검산 y_t = Σ K_k x_(t−k)결과
K₀ = C B̄0.5000y₁ = K₀x₁ = 0.5×10.5000
K₁ = C Ā B̄0.3033y₂ = K₀x₂ + K₁x₁ = 0 + 0.30330.3033
K₂ = C Ā² B̄0.1839y₃ = K₀x₃ + K₁x₂ + K₂x₁ = 1.0 + 0 + 0.18391.1839

앞 절의 순차 계산 결과(0.5 / 0.3033 / 1.1839)와 정확히 일치합니다.

이 커널은 입력과 무관(LTI)해서 한 번 계산하면 재사용 가능(고속 합성곱). 대신 “입력에 따라 선택”은 불가능 — 그래서 다음 절(선택성)이 필요합니다.

수식 ③ — 병렬 스캔(associative scan)

Δ,B,C가 입력 의존이면 커널이 매번 달라져 합성곱을 못 씁니다. 하지만 순차 재귀 자체를 병렬화할 수 있습니다. 선형 재귀를 아핀 형태로 봅니다.

$$ h_t = a_t\,h_{t-1} + b_t, \qquad a_t = \bar A_t,\quad b_t = \bar B_t\,x_t $$

쌍 (a, b) 를 함수 z ↦ a·z + b 로 보면 합성은

$$ (a_2,b_2)\circ(a_1,b_1) = \big(a_2 a_1,\; a_2 b_1 + b_2\big) $$

이 연산은 결합법칙이 성립합니다(교환은 아님). 따라서 앞에서부터의 합성(prefix)을 병렬 스캔으로 계산할 수 있습니다.

$$ (A_t, B_t) = (a_t,b_t)\circ\cdots\circ(a_1,b_1), \qquad h_t = B_t $$

수치 예: a = [0.5, 0.5, 0.5], b = [1, 0, 2]

tprefix (A_t, B_t)h_t = B_t
1(0.5000, 1.0000)1.0000
2(0.2500, 0.5000)0.5000
3(0.1250, 2.2500)2.2500

순차 재귀(h₂=0.5·1+0=0.5, h₃=0.5·0.5+2=2.25)와 일치.

결합법칙 덕분에 O(L) 작업을 O(log L) 깊이로 병렬화할 수 있습니다(Blelloch 스캔). GPU/다중코어에 유리하고, CPU에서 tf.scan 이 이 원리를 사용합니다.

Mamba의 핵심 — 선택성(Selective)

위의 Ā,B̄,C가 상수면 병렬화되지만 “입력에 따라 선택”을 못 합니다. Mamba는 이들을 입력 x_t마다 다르게 만듭니다.

Δ_t = softplus(Linear_Δ(x_t))
B_t = Linear_B(x_t)
C_t = Linear_C(x_t)          # 입력이 “무엇을 기억/무시할지” 결정
입력 토큰 x = 1

입력이 바뀌면 게이트(Δ,B,C)가 바뀝니다 → 정적 컨볼루션으로는 불가능 → 병렬 스캔으로 O(L) 구현.

PyTorch — 정답 오라클(순차 루프)

import torch
import torch.nn.functional as F

def selective_scan(u, delta, A, B, C, D=None):
    # u, delta: (b, d, l)   A: (d, n)   B, C: (b, n, l)
    b, d, l = u.shape
    n = A.shape[1]
    delta = F.softplus(delta)                 # Δ > 0
    dA   = torch.exp(delta[..., None] * A)    # (b,d,l,n) = exp(ΔA)
    dB_u = (delta[..., None]
            * B.transpose(1, 2)[:, None]      # (b,1,l,n)
            * u[..., None])                   # (b,d,l,1)
    h = u.new_zeros((b, d, n))
    ys = []
    for t in range(l):
        h = dA[:, :, t] * h + dB_u[:, :, t]   # h_t = Ā h_{t-1} + B̄ x_t
        ys.append(torch.einsum("bdn,bn->bd", h, C[:, :, t]))
    y = torch.stack(ys, dim=2)
    if D is not None:
        y = y + u * D.view(1, -1, 1)          # skip
    return y

TensorFlow — tf.scan으로 병렬화

import tensorflow as tf

def selective_scan_tf(u, delta, A, B, C):
    # u, delta: (b, l, d)   A: (d, n)   B, C: (b, l, n)
    delta = tf.nn.softplus(delta)
    dA  = tf.exp(delta[..., None] * A)                 # (b,l,d,n)
    dBu = delta[..., None] * B[:, :, None, :] * u[..., None]

    def step(h, xs):
        dA_t, dBu_t, C_t = xs
        h = dA_t * h + dBu_t
        y = tf.reduce_sum(h * C_t[:, None, :], axis=-1)
        return h, y

    h0 = tf.zeros([tf.shape(u)[0], tf.shape(u)[2], A.shape[1]])
    _, ys = tf.scan(
        step,
        (tf.transpose(dA,  [1, 0, 2, 3]),
         tf.transpose(dBu, [1, 0, 2, 3]),
         tf.transpose(C,   [1, 0, 2])),
        initializer=h0)
    return tf.transpose(ys, [1, 0, 2])

왼쪽 순차 루프는 “정답” 기준, 오른쪽 tf.scan은 같은 계산을 병렬화. 둘의 출력이 수치적으로 일치하는지가 구현의 첫 관문(허용오차 < 1e-5).

양방향 스캔 — 이미지는 순서가 없다
